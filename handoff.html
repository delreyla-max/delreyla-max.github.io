Shared / Global Files

nav.js

Single source of truth for the navigation across all pages. Injects nav HTML + CSS + JS into every page at runtime. To update the nav (links, logo, styling), edit only this file.

  • Logo: GARMAN Y. linking to index.html
  • Links: Work → all-projects.html, Resume → resume.html, Contact → contact.html
  • Active state: red underline on current page link; homepage highlights the brand name
  • Mobile: hamburger menu, black overlay drawer, slides down from under nav
  • Desktop hover: red #dc2626 underline on all nav links

projects-data.js

All project content for the all-projects.html grid and project.html template. Add, edit, or reorder projects here without touching HTML.

Homepage Animation (desktop)

The desktop homepage uses a custom scroll-scrub engine with a video intro phase.

Animation phases

  • video1 — Intro video plays automatically on load (frames/frames1/frames1.mp4)
  • toyota-hold — Video ends, holds on last frame. Scrub hasn't started yet.
  • scrub — User scrolls down; video hides, canvas shows, frame sequence begins
  • done — All frames scrubbed through

Scrolling back to top from scrub restores the held video frame.

Frame sequences

Stored in frames/ subdirectories. The canvas scrub reads sequential JPEGs. The intro video is frames/frames1/frames1.mp4.

Resume Page

Two separate Google Docs

PurposeDoc
Iframe (public, no contact info) 2PACX-1vTE-f1_-pZi2wnhGWd…
Download button (with contact info) 2PACX-1vR354cYhmbs1Ybps…
The iframe displays the doc without phone/email to reduce spam exposure. The download button fetches the full resume PDF (with contact info) every time — always the latest version.
Google Docs publish cache has a 5–30 min delay after edits. This is not controllable from the site.

Mobile iframe workaround

Google Doc internal margins make the iframe content appear shifted left on mobile. Compensated with width: calc(136% + 40px); margin-left: calc(-18% - 20px). The overflow-x: clip on html/body prevents horizontal page scroll.

Contact Form

Submissions go to a Google Apps Script endpoint. The URL is hardcoded in contact.html. Name, email, and message are sent as JSON via fetch POST.

Known Quirks

  • Google Docs iframe renders fonts unreliably — Oswald may fall back to Times New Roman. Switching the doc font to Inter fixes this.
  • index.html (desktop) and index-mobile.html are separate pages — the site does not auto-redirect between them.
  • Inline nav CSS remains in some page <style> blocks (harmless redundancy — nav.js overrides).
  • Smart quotes in JS string literals will break all project pages — run fix-quotes.ps1 if projects stop rendering.
